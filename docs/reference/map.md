# learncroc map

map.yaml: lines and the prerequisite graph of cards, checkpoints and planned cards. Generated by `bun run schemas` from the zod schemas in `packages/core/src/schema`; do not edit.

JSON Schema: [`schemas/map.schema.json`](../../schemas/map.schema.json) (`https://learncroc.github.io/schema/v1/map.schema.json`).

## map.yaml

| Field | Type | Required | Notes |
|---|---|---|---|
| `lines` | `MapLine`[] | yes | 1–5. |
| `nodes` | map of `MapNodeEntry` | yes |  |

| Field | Type | Required | Notes |

| `color` | `LineColor` | yes |  |

## map.yaml → nodes

| Field | Type | Required | Notes |
|---|---|---|---|
| `requires` | `NodeId`[] | yes | Prerequisites (cards or checkpoints). Cards of section n+1 require section n's checkpoint. |
| `line` | `LineId` | yes |  |
| `kind` | `"node"` \| `"checkpoint"` |  | Default "node". |
| `status` | `"playable"` \| `"planned"` |  | Default "playable". Planned: no node file (samplers: only beyond the final checkpoint). |
| `title` | string |  | Required for planned entries. Checkpoint default: theme.gateName ?? "Checkpoint <n>". |
| `teaser` | string |  | Required for planned entries. Optional for checkpoints (shown on the gate's peek). |
| `covers` | `NodeId`[] |  | Checkpoint only: the cards it tests. Default: its section (checkpointCovers). |
| `size` | integer |  | Checkpoint only: questions per attempt, 3–5. Default: defaultCheckpointSize. |
| `pin` | object |  | Optional layout hint. |
