# Pre-flight checklist (the learning principles)

Run through this before writing a stop, and again before calling it done.

## Rule zero: do, don't just read
- [ ] Every screen and the hook end in an action: guess, sort, order, set, type, explain.
- [ ] Teach before you test: only the hook is a guess. Every graded question is about something shown earlier in the stop (a story, a worked example, a source passage or a hands-on visual).
- [ ] ≤ 30 words of setup before the action; ≤ 50 in a reveal; ≤ 40 in the hook (blocks and reveal).
- [ ] ≤ 350 learner-facing words in the whole stop (hook + every screen's blocks, prompt and reveal).
- [ ] No "Continue" / "Next" interactions. The learner moves on by doing the next thing.

## Evidence-based
- [ ] **A1 Retrieval:** answering is the main activity; the item bank is real practice, not trivia.
- [ ] **A2 Guess first:** the hook is about the stop's `bigIdea` and is answerable by guessing; screen 1 then shows what answers it.
- [ ] **A5 One idea per screen, with a picture:** at most one `newIdea` per screen; every screen has a visual.
- [ ] Answers given with help never count (the app enforces this; don't design around it).

## Playful
- [ ] **B1 Curiosity first:** open with a puzzle or a surprising fact, never a definition ("X is …").
- [ ] **B5 Story over explanation:** setup is a 2–3 line micro-story with a concrete person, place or object.
- [ ] Voice: dry, warm, adult. No exclamation marks, emoji, "Great job", "Most people", streaks or XP.
- [ ] "Lots of people guess X" only when it's true of your hook's likely answers.

## DAG
- [ ] **C2:** a stop only requires stops it truly cannot be understood without.
- [ ] **C5:** every misconception's `upstream` is an ancestor stop (or `in-node:<screenId>`), so the Stuck helper can walk back.

## Never
- [ ] No wall of text. No "learning styles". No streak guilt, XP or leaderboards.

## Honesty
- [ ] Every number is sourced, precomputed with a named model, or labelled illustrative.
- [ ] `status: draft`. Reviews are added by named humans only.
