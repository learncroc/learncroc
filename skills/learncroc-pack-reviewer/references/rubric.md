# Review rubric (score 1–5, quote evidence for each)

| # | Criterion | 5 looks like | 1 looks like |
|---|---|---|---|
| 1 | **Hook pulls** | A surprising, answerable guess about the core idea; lots of people would guess wrong | A definition, a trivia question, or the answer is in the prompt |
| 2 | **Hands do the idea** | The learner's action *is* the concept (drag the weights, sort the cases, set the number) | Clicking through options that could be any topic |
| 3 | **Show before test** | Each idea is shown (story, example, manipulation) before it's needed | A screen tests something nothing showed |
| 4 | **One idea per screen** | Each screen adds at most one new idea, with a visual that carries it | Two ideas crammed together, or a text-only screen |
| 5 | **Reveals land** | Reveals name what just happened in ≤ 50 words | Reveals re-explain at length, or repeat the setup |
| 6 | **Misconceptions are real** | Wrong options are beliefs adults actually hold, each with an upstream that would help | Silly distractors; upstream points nowhere useful |
| 7 | **Transfer** | The last screen and transfer items apply the idea in a new situation | The last screen repeats the first with new numbers only |
| 8 | **Practice quality** | Items test understanding, ≤ 40% choice, parametric where numbers vary, no True/False | Recall-only trivia, mostly multiple choice |
| 9 | **Voice** | Dry, warm, adult; concrete micro-stories; no hype | Exclamation marks, praise, baby talk, textbook prose |
| 10 | **Honesty and grounding** | Every number sourced, precomputed with a named model, or labelled illustrative | Invented statistics or unattributed claims |

Pass bar for proposing a pack to the registry: no criterion below 3, average ≥ 4, and lint clean.
