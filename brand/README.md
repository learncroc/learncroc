# Learncroc brand

The croc and the logo.

## Files

Everything in [`assets/`](assets) is generated by `bun brand/export.ts` from [`croc.js`](croc.js), the one
drawing every croc comes from. Edit the drawing there, re-run the export, commit the outputs.

| File | Use |
|---|---|
| `logo.svg` · `logo-dark.svg` · `logo.png` · `logo-dark.png` | Primary lockup: the croc's head beside the wordmark. Light and dark backgrounds |
| `logo-stack.svg` · `logo-stack-dark.svg` | Stacked, for square spaces |
| `logo-peek.svg` | The croc peeking over the wordmark, for page headers and loading screens |
| `wordmark.svg` · `wordmark-dark.svg` | The wordmark alone |
| `mark.svg` | The croc's head alone |
| `icon.svg` · `icon-512.png` · `icon-light.svg` | App icon: the flat head on a night (or belly-green) tile |
| `favicon.svg` | The eyes over the water, the one shape that reads at 16 px |
| `avatar.png` · `avatar-dark.png` · `avatar-full.png` | Profile pictures (safe inside a circle crop) |
| `croc.svg` · `croc-head.svg` · `croc-happy.svg` · `croc-thinking.svg` · `croc.png` | The mascot, for docs and slides |
| `croc-proud-gold.svg` | The gold croc. Only next to a stop being lit or a finished map |
| `readme-banner.png` · `readme-banner-dark.png` | The README header, 1280 × 640 (also the GitHub social preview) |

The export also writes the web app's `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable*.svg/png` and
`apple-touch-icon.png` into `apps/web/public/`.

In the app, use `<Logo />`, `<Wordmark />` and `<Croc />` from `@learncroc/ui`. `<Croc pose="head" still />` is
the logo croc; the default is the full, living mascot.

## Rules

- **Jade is the croc.** Logo, app icon, favicon, and anywhere the croc stands for Learncroc. Body `#5bbf8e`,
  shade `#2f8a63`, belly `#d9f2bd`.
- **Gold means you know it.** The croc turns gold only for a moment when a stop lights up, so gold keeps its
  meaning.
- **There is no red croc.** In a learning app red reads as wrong, and the croc is never the thing that tells
  you off.
- **The logo holds still.** Flat colour, no clay grain, no shadow, no expression other than hello.
- **The wordmark is lowercase**: `learncroc`, set in Recursive at weight 830 with the casual and cursive axes
  on (CASL 1, CRSV 1) and −0.035 em tracking. In running text the name is written Learncroc.
- Leave clear space of at least one eye bump (about 0.4 em of the wordmark) around the lockup. Don't recolour,
  outline, stretch or rotate it.

The other colours in the family (sea, moss, sky, iris, blush, ember, night) are for map themes and learner
avatars, never for the logo.
